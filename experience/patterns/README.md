# patterns/ - 解决问题模式

存放「卡 X 问题 -> 用 Y 方法解决」的可复用模式。

## 文件命名
`YYYY-MM-DD-<slug>.md`（如 `2026-07-24-tauri-ime-conflict.md`）

## 适用问题类型
- debug：调试踩坑（崩溃/异常/无报错但行为错）
- perf：性能优化（启动慢/内存/网络）
- security：安全（凭据/XSS/注入）
- i18n：国际化与编码（GBK/UTF-8/中文乱码）
- build：构建与打包（依赖/版本/跨平台）
- async：异步与并发（线程/协程/锁）
- net：网络与代理（CORS/VPN/防火墙）
- ...
